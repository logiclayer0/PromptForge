# ⚡ PromptForge - AI Prompt Generator

## 📝 Description
PromptForge is a powerful AI prompt generator that creates multiple unique prompts from just 3-4 words. Perfect for students, artists, writers, developers, and professionals across all fields.

## ✨ Features
- 🎯 10+ Categories (Art, Coding, Writing, Education, Business, Health, Travel, Tech, Social Media, Lifestyle)
- 🎨 7 Tone Options (Professional, Casual, Funny, Formal, Inspiring, Dramatic, Minimalist)
- 📊 5-15 Prompt Variations
- 📋 Copy, Save, Regenerate, Export
- ⭐ Favorites with LocalStorage
- 🌙 Dark/Light Mode
- 📱 Fully Responsive
- 🚀 No frameworks - Pure vanilla JS

## 🚀 How to Use
1. **Enter 3-4 words** (e.g., "cat wearing hat")
2. **Select Category** (Art, Coding, Writing, etc.)
3. **Choose Tone** (Professional, Funny, etc.)
4. **Pick number of options** (5-15)
5. **Click Generate** ⚡
6. **Copy, save, or regenerate** your favorite prompts
